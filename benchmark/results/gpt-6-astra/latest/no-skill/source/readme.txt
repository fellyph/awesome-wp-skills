Northline — WordPress 6.9 block theme

Install the theme folder (or a ZIP of it) using Appearance > Themes. The benchmark installation inserts benchmark-fixture/landing into its published home page. For a separate installation, create a page, insert the Agency landing page pattern, and select that page as the static homepage in Settings > Reading.

Editing
Open the Home page in the standard WordPress page editor. The headline is a Heading block, the hero artwork is an Image block, and Start a project is a Button block. Edit these blocks and save the page; the front-page template renders that saved page content. All other page sections are native blocks too. Header and footer are reusable template parts available in the Site Editor.

Alternative artwork
assets/replacement.svg is retained alongside the three original artworks. To use it, select the hero Image block, choose Replace > Insert from URL, and use this theme's local assets/replacement.svg URL (the current image URL with studio.svg changed to replacement.svg). Update the image alternative text to describe the replacement.

The contact section uses the supplied [benchmark_contact] shortcode. The theme only styles its form; validation and local synthetic submission storage remain with the fixture. No external services, fonts, images, or submission endpoints are used.
